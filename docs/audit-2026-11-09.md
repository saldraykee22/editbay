## Key changes

**Shared core (lead)**
- Transition overlap became part of core timeline math (`clampTransitionOverlapMs`, `transitionOverlapMs`, `projectDurationMs`), consumed by engine, prompt, MCP and preview. Clamp is half of the shorter clip, matching `validateProject`.
- Every successful command normalizes tracks: dangling/oversized transitions removed or clamped, fades and effect windows kept inside the clip.
- `duplicate_clip` gets fresh transition ids; `add_audio` rejects silent video and <100 ms clips; `EditSession.fromJSON` validates; muted audio no longer extends duration.

**Desktop**
- Ctrl+S saves the project, autosave follows the opened file, New/Open confirm before discarding, revision guard against stale saves.
- `editbay-media://` allowlist (403 otherwise), dialog-authorized project/export writes, `secrets:has` instead of plaintext `secrets:get`, 0o600 secret file + honest "unencrypted" warning.
- Brand id is attached to the project and loaded by the agent; one shared front-matter parser (hex colours, no duplicate headings).
- Timeline: audio/overlay drag uses `set_audio_start`, trim respects speed, Inspector uses `applyBatch`, `"0"` no longer coerced to 1.
- Preview: audio-track playback, volume/speed/mute sync, transition crossfade, text geometry matches drawtext.
- Chat Stop button + abort; OAuth state verified; playhead no longer re-renders the app or reschedules autosave.

**Engine / effects**
- `format=rgba` before scale + even dimensions; silent-audio guard; encoder resolution (`libx264 → libopenh264 → videotoolbox/mf/nvenc`, override env); packaged font paths; attached-pic probe; audio fades on clips; quote-aware filter windowing (no `enable` on zoompan); input-level `-ss/-to`; Windows temp cleanup; `new Function` removed (declarative custom effects).

**Harness**
- Proposal mode omits/rejects `apply_commands`; Gemini `thoughtSignature` preserved; prompt-injection boundaries; abort signal + retry with `Retry-After`; 24-message history cap; accurate stop-on-first-failure text + `skipped`; brand/skill id validation; overlay removed from tool text.

**Kit / CLI / MCP / CI**
- Save mutex + unique temp + atomic import undo; MCP `createdIds` and full project view; brand traversal rejected; CI runs tests on Windows/macOS; license notices; skills bundled into CLI/MCP dist and resolved outside the repo.

## Known deviations

- `dissolve` previews as a plain crossfade; the export uses ffmpeg's random per-pixel dissolve. `circleopen` and `zoomin` preview as close approximations of the ffmpeg curves (midpoint frames match). Every other transition draws the real `xfade` geometry in both preview and export (`transitionFrame` in `@editbay/effects`, pinned to ffmpeg by `packages/engine/src/transition.e2e.test.ts`). Text geometry and audio/speed/mute are exact.
- Overlay clips are composited above the main video and below text; an overlay video's own audio is not mixed yet.
- FFmpeg is bundled only when the release build ran `pnpm fetch:ffmpeg` (LGPL, Windows/Linux); otherwise `PATH` or `EDITBAY_FFMPEG` is used. macOS needs a user-supplied build.
- Media allowlist: assets from a pre-audit `projects/current.json` are authorized at startup from the workspace recovery file; other legacy paths must be re-opened once.
